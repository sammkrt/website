01PLATFORM ENGINEERING

Making state work
across servers.

Moving import and export workflows away from server-bound session state.

ASP.NET CoreCachingRefactoring
Inside the work

The challenge

Workflows that rely on an HTTP session are harder to reason about when requests can reach different servers.

My contribution

Helped replace session dependencies with explicit state management and cache-backed import and export flows, then verified the changes in acceptance testing.

Why it matters

State has a clearer home, and the workflow relies less on a particular web server.
